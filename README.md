# 무인도 생존 교육 시스템 (Python 미니 프로젝트)

| 항목 | 내용 |
|---|---|
| 장르 | 교육 프로그램 |
| 주어 | 미래의 나 |
| 공간 | 무인도 |
| 돌발 상황 | 예상하지 못한 손님이 등장한다 |
| 파일 | `island_system.py` (파일 하나, 설치 필요 없음 — Python 기본 tkinter 사용) |
| 실행 | `py island_system.py` |

## 내 해석

> 10년 뒤의 나는 무인도에 표류했다가 살아남았다. **미래의 나**는 그 경험을 과거의 나에게 전하려고,
> 게임 속 '시스템 창'처럼 눈앞에 떠오르는 **생존 교육 시스템**을 설계했다.
> 시스템은 퀘스트(생존 지식 문제)를 내고, 클리어하면 경험치가 쌓여 레벨이 오르며,
> 레벨업할 때마다 미래의 내가 보낸 구조 헬기가 보급 상자를 떨어뜨린다.
> 그런데 섬 생활 도중 **예상하지 못한 손님** — 해안가로 떠밀려 온 표류자들 — 이 나타난다.
> 구한다고 모두 도움이 되는 것은 아니다. 단서를 관찰해 정체를 추리하고, 믿을지·경계할지·지켜볼지 선택해야 한다.

## 요소별 반영 위치

| 요소 | 이야기 | 화면 | 규칙 | 데이터 |
|---|---|---|---|---|
| 교육 프로그램 | 생존 지식 + 사람을 보는 판단력 훈련 | 퀘스트 영역·입력칸·힌트·결과 요약 | 정답 비교 판정, 오답 시 힌트, 재도전 | `QUESTS` (질문·정답 여러 개·힌트) |
| 미래의 나 | 시스템 설계자, 힌트·해설 제공자, 보급 헬기 발송자 | 보라색 `[미래의 나]` 대사 | 힌트는 1회 오답 또는 신호탄 사용 시 | 각 퀘스트 `hint`, 표류자 `explain` |
| 무인도 | 생존 1일차 | 시스템 창, 해안가·섬·헬기 애니메이션 | 물·불·구조·수분·방향 주제, 가방 아이템 | `SUPPLIES`, `inventory` |
| 예상하지 못한 손님 | 해안가로 떠밀려 온 표류자 5명 | 빨간 돌발 미션 창, 표류 애니메이션, 단서 ①②③ | 무작위 발생(40%) → 대기열 → 선택 → 정체 공개 | `CASTAWAYS`, `pending_events`, `judge_log` |

## 핵심 기능 3개

1. **퀘스트 출제와 답 입력** — 5개 퀘스트를 차례로 출제, Enter 키/확인 버튼으로 제출
2. **판정과 힌트** — 정답 여러 개 인정(공백·대소문자 무시), 1회 오답 시 미래의 나 힌트, 2회 오답 시 실패
3. **성장과 복습** — EXP·레벨업(보급 헬기 애니메이션), 실패 퀘스트를 재도전 목록에 모아 다시 풀기, 결과 요약

## 돌발 상황 재현과 해결

- **재현**: 퀘스트가 끝날 때마다 40% 확률로(레벨업했으면 헬기 연출 직후에) 표류자가 해안가로 떠밀려 온다.
  시연할 때는 **F2 키**로 즉시 발생시킬 수 있다.
- **해결**:
  1. 돌발 미션을 대기열(`pending_events`)에 넣고, 진행 중인 화면 위에 미션 창을 덮어 띄운다.
  2. 뒤의 퀘스트 번호·레벨·EXP·재도전 목록·입력하던 글자는 **건드리지 않는다**(입력만 잠금).
  3. 단서를 보고 [믿는다 / 경계한다 / 지켜본다] 중 선택 → 결과·정체·해설을 보여 준다.
  4. [계속]을 누르면 대기열의 다음 미션을 처리하고, 다 끝나면 원래 진행으로 돌아간다.

## 시연 순서 (약 3분)

1. Q1을 풀다가 입력칸에 "소"만 쓴 상태에서 **F2** → 표류자 등장 애니메이션
2. 단서 ①② 확인 → [더 살펴보기]로 단서 ③ → 선택 → 결과·정체·미래의 나 해설
3. [계속] → Q1 화면과 입력칸의 "소"가 그대로 남아 있음을 보여 줌 (**진행 상태 유지**)
4. 퀘스트를 계속 맞혀 레벨업 → 헬기 보급 애니메이션 → (무작위 표류자)
5. 가방에 신호탄이 생기면 [신호탄 쏘기]로 힌트 받기 (직접 수정한 기능)
6. 일부러 두 번 틀려 재도전 라운드 → 결과 요약

## 직접 수정한 기능

| # | 발견한 문제 | 수정 내용 |
|---|---|---|
| 1 | 0단계 시험에서 "염분"을 입력 → 맞는 답인데 정답이 "소금" 하나뿐 | 정답을 리스트로 바꿔 여러 개 인정, 공백·대소문자 무시(`normalize`) |
| 2 | EXP 막대 □가 너무 작아 안 보임 | 글꼴을 Consolas → 맑은 고딕으로 변경 |
| 3 | 헬기 애니메이션이 끝날 때 tkinter 내부 오류 | 그림판이 자기 타이머 안에서 자신을 지우던 문제 → `cv.after` 대신 `root.after` 사용 |
| 4 | 손님이 버튼을 눌러야만 등장해 '예상하지 못한' 느낌이 없음 | 무작위 발생 + 표류 애니메이션 + 단서 추리 선택으로 개편 |
| 5 | 표류자 그림이 너무 작음 | `cv.scale`로 1.6배 확대 |
| 6 | 보급품이 가방에 쌓이기만 하고 쓸 데가 없음 | **신호탄 쏘기**: 신호탄 1개를 소모해 힌트를 미리 보기 (EXP는 절반) |

## 웹 확장판 (`web/` 폴더)

tkinter 버전(제출용)과 같은 규칙을 브라우저 화면으로 옮긴 확장판이다.

| 파일 | 역할 |
|---|---|
| `web/app.py` | Flask 웹 서버. 주소(/api/...)로 요청을 받아 판정 결과를 돌려준다 |
| `web/game_data.py` | 퀘스트·표류자 데이터와 판정 규칙 (정답·정체는 서버에만 있고 브라우저로 보내지 않음) |

| `web/static/style.css` | 시스템 창 디자인 |
| `web/static/game.js` | 화면 동작·애니메이션 (헬기 보급, 표류자 떠밀려 오기, 시작 화면 타자 효과) |
| `web/static/img/` | perchanceai.app에서 생성한 일러스트 7장 (표류자 5명, 미래의 나, 해안가 배경) |
